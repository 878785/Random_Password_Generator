# 🔐 Random Password Generator

A responsive Random Password Generator built using HTML, CSS, and JavaScript. It helps users generate passwords by choosing their preferred length and character types.

## 🌐 Live Demo

[Click here to try the Password Generator](https://878785.github.io/Random_Password_Generator/)

## ✨ Features

- Adjustable password length from 4 to 32 characters
- Uppercase and lowercase letters
- Numbers and special symbols
- One-click copy functionality
- Password strength indicator
- Responsive and modern dark-themed UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Web Crypto API (for secure random number generation, if implemented)

## 🚀 How to Use

1. Open the live demo.
2. Select your desired password length.
3. Choose the character types you want to include.
4. Click **Generate Password**.
5. Click **Copy** to copy the generated password.
